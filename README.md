# David Donika Panjaitan · Portfolio

Personal portfolio website of **David Donika Panjaitan**, Senior Backend Developer and Full-Stack Developer (Java / Spring, Node.js, React) based in Jakarta, Indonesia.

- **Live site:** _add the URL after the first deploy_
- **LinkedIn:** <https://www.linkedin.com/in/david-donika-panjaitan>
- **GitHub:** <https://github.com/daviddonikapanjaitan>

## Tech stack

- [Next.js 16](https://nextjs.org) (App Router, fully static) + TypeScript
- Tailwind CSS v4
- `next/font` (Geist, Geist Mono), `next/image`
- `next-themes` (light / dark / system), `lucide-react` icons
- ESLint + Prettier

There is no backend and no database: all content lives in typed data files.

## Run locally

Requires Node.js 20.9 or newer (current LTS recommended).

```bash
npm install
npm run dev        # http://localhost:3000
```

Other scripts:

| Script                 | What it does                                                             |
| ---------------------- | ------------------------------------------------------------------------ |
| `npm run build`        | Production build (used by Vercel)                                        |
| `npm run start`        | Serve the production build                                               |
| `npm run lint`         | ESLint                                                                   |
| `npm run typecheck`    | TypeScript check                                                         |
| `npm run check`        | Lint + type-check + build                                                |
| `npm run format`       | Prettier                                                                 |
| `npm run build:static` | Static export to `out/` (GitHub Pages)                                   |
| `npm run assets`       | Regenerate the photo, OG image and icons from `assets/profile_photo.png` |

## How to update content

Edit the files in `src/data/`. The layout never needs to change.

| File                     | Content                                                                                                           |
| ------------------------ | ----------------------------------------------------------------------------------------------------------------- |
| `src/data/profile.ts`    | Name, headline, tagline, location, email, links, About text, "open to opportunities" flag                         |
| `src/data/skills.ts`     | Skill groups (`core: true` highlights a skill)                                                                    |
| `src/data/experience.ts` | Jobs. Dates use `YYYY-MM`; `end: "present"` for the current job. Sorted automatically, newest first               |
| `src/data/projects.ts`   | Personal projects (`personalProjects`, with screenshot and GitHub link) and enterprise project cards (`projects`) |
| `src/data/education.ts`  | Education and certifications                                                                                      |
| `src/data/clients.ts`    | Client names and their anonymous versions                                                                         |

Switches in `src/lib/site.ts`:

- `showClientNames`: set to `false` to replace CIMB / Allianz / Tokio Marine with anonymous descriptions.
- `showGpa`: show or hide the GPA.
- `sourceUrl`: optional link to this repository in the footer.

"Years of experience" and job durations are calculated from the dates at build time, so they update on every deploy.

### Public files

- `public/resume.pdf`: **public** CV (home address and phone number removed). Replace it when the CV changes.
- `assets/`: **private** originals (full CV, raw photo). Git-ignored as a whole folder, so they are never published.
- `public/images/profile.webp`, `public/og-image.png`, `public/icon-*.png`, `src/app/icon.png`, `src/app/apple-icon.png`, `src/app/favicon.ico`: generated by `npm run assets`.

## Deploy

### Vercel (recommended)

1. Push this repository to GitHub.
2. In Vercel: **Add New → Project → Import** the repository. The Next.js preset is detected automatically; no settings or environment variables are needed.
3. Every push to `main` deploys production; every pull request gets a preview URL.
4. Optional: add a custom domain in **Settings → Domains**, then set `NEXT_PUBLIC_SITE_URL` (e.g. `https://example.com`) in **Settings → Environment Variables** so canonical and social links use it. Without it, the Vercel production URL is used.

### GitHub Pages (alternative)

Step-by-step guide: **[docs/DEPLOY.md](docs/DEPLOY.md)**. The workflow `.github/workflows/deploy-pages.yml` builds and publishes the site on every push to `main`.

Build a static export:

```bash
# Repo named daviddonikapanjaitan.github.io (site at the root):
NEXT_PUBLIC_SITE_URL=https://daviddonikapanjaitan.github.io npm run build:static

# Any other repo name, e.g. "portfolio" (site at /portfolio):
NEXT_PUBLIC_BASE_PATH=/portfolio \
NEXT_PUBLIC_SITE_URL=https://daviddonikapanjaitan.github.io/portfolio \
npm run build:static
```

Upload the `out/` folder with the official "Deploy to GitHub Pages" action (**Settings → Pages → Source: GitHub Actions**).
